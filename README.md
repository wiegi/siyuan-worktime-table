# siyuan-worktime-table
A SiYuan plugin for creating and editing worktime tables with automatic totals, subtotals and offsets. Sibling of [logseq-worktime-table](https://github.com/wiegi/logseq-worktime-table).

**Status:** early scaffold, not functional yet.

`src/core/` is shared logic copied from the Logseq plugin (time parsing, table build/parse, CSV).
